# RTI Demo UI

RTI Demo UI is a small SDK for building local browser interfaces for RTI
Connext DDS demos. Applications define cards and stateful components in Python
or C++; the SDK serves the shared browser frontend without requiring a separate
frontend process or a runtime dependency on Connext.
